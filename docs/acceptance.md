## 桌面 Chrome / Edge

- [ ] 上传图片，OSS 控制台可见对象；图片页相册可见
- [ ] 上传 PDF，文件列表可预览
- [ ] 上传 `.docx`，可预览；`.doc` 有明确提示并可下载
- [ ] 文件列表：搜索 / 类型筛选 / 排序 / 分页正常
- [ ] 「显示全部文件」开/关：扁平列表 ↔ 层级目录 + 面包屑
- [ ] 预览弹窗：图片缩放/切换；点遮罩可关闭
- [ ] 下载为本机文件（非 AccessDenied 跳转页）
- [ ] 复制签名链接可打开（注意过期时间）
- [ ] 删除确认后列表更新，OSS 对象消失

## 手机 Safari / Chrome

- [ ] 同上：上传图片、PDF、docx 并可预览
- [ ] 底栏 Tab：上传 / 文件列表 / 图片
- [ ] 列表为卡片布局；触控区域可点
- [ ] 图片页相册：按日分组、缩略图、预览左右切换
- [ ] 安全区：顶栏 / 底栏不被刘海或 Home 条遮挡（见 mobile-qa）

## 校验与错误

- [ ] 超大文件：触发单文件 / 总体积上限提示
- [ ] 非法扩展名：拦截并提示
- [ ] 断网或 STS 失败：有可读错误（非空白）
- [ ] CORS 错误：提示可读（Origin / Method 排查见 faq）

## 私有读与签名

- [ ] Bucket 私有读时，预览 / 缩略图可打开
- [ ] 签名过期后刷新或重新打开仍可访问（失败有重试 / 刷新路径）

## 性能抽查（8.6）

- [ ] 首屏可交互，无明显长时间白屏
- [ ] 首次打开 PDF / Word 可接受（异步 chunk）
- [ ] 相册大量图片时滚动无明显卡死、内存无明显持续飙升

| 菜单 | 路径 | 职责 |
