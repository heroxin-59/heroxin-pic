# 移动端自测清单（阶段 6.6）

> 建议在 Chrome DevTools「设备工具栏」与至少一台真机各测一遍。断点约定见 `src/constants/breakpoints.ts`（与 Element Plus 对齐）。

## 环境

- [ ] 竖屏手机宽度（xs，&lt; 768）：底部 Tab + 顶栏页标题
- [ ] 平板 / 桌面（sm+，≥ 768）：顶栏横向导航，无底栏
- [ ] 横屏短屏（高度 &lt; 500）：底栏压缩，标签隐藏，内容区仍可滚动
- [ ] 刘海 / Home 条设备：顶栏、底栏、主内容未被遮挡（`viewport-fit=cover` + safe-area）

## 上传

- [ ] 「拍照上传」「选择文件」大按钮可点（≥ 44px）
- [ ] 多选上传、进度、取消、重试正常
- [ ] 超大 / 非法类型有友好提示

## 列表

- [ ] 桌面为表格，手机为卡片
- [ ] 搜索 / 筛选 / 排序 / 分页可用
- [ ] 预览、下载、复制、删除确认弹窗不裁切

## 预览

- [ ] 图片：缩放 / 旋转 / 滑动切换 / 全屏
- [ ] PDF：翻页 / 缩放（含中文扫描件）
- [ ] Word：`.docx` 可预览；`.doc` 提示下载
- [ ] 文本：`.txt` / `.md` / `.json` / `.csv` 可读

## PWA（6.7）

- [ ] 浏览器可识别 `manifest.webmanifest`
- [ ] iOS Safari「添加到主屏幕」后以独立窗口打开（无离线缓存要求）
